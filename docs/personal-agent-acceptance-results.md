# Personal Agent 当前能力验收结果

日期：2026-11-04；对应标准：[V1 必备能力](personal-agent-acceptance.md)。

## 本轮测试

- 真实模型：doubao-seed-2-1-pro-260915；实际执行框架：nanobot 0.4.0。
- 12 项真实模型用例通过。每项启动独立 Python 进程；测试资料和运行目录隔离，无生产用户资料写入。
- 57 项离线测试通过，覆盖确认状态机、推荐、语音协议、运行时工具／命令边界、持久化、任务中断和调度宿主。
- 当前 HTTP 健康、底座、历史和任务接口返回 200。麦当劳真实只读门店查询返回 5 家，测试地点为公开的上海人民广场。
- 没有创建真实订单、支付、叫车或通知。

## 架构能力判定

| 能力 | 判定 | 证据与边界 |
| --- | --- | --- |
| F01 运行时与聊天 | 通过现有用例 | 真实框架与模型；普通聊天不走点餐工具 |
| F02 稳定个人身份 | 通过单机范围 | 不同 owner／新线程共享同一单机资料，聊天仍隔离 |
| F03 个人记忆增改删 | 通过显式资料范围 | 真正入库、更新、临时约束不保存、删除后不召回；不是自动人格建模 |
| F04 会话与历史 | 部分完成 | 新进程恢复当前聊天和执行记录已通过；完整历史检索体验未验收 |
| F05 多场景 Skill 协作 | 部分完成 | 注册层与核心资料／任务工具已有，真实生活领域仍主要是麦当劳 |
| F06 持续办事目标 | 部分完成 | 当前记录的是每轮执行回执和订单方案；还不能完整管理待补充、暂停、继续、取消的同一目标 |
| F07 用户安排的定时提醒 | 未完成 | 引擎 running、jobs=0、user_scheduling_enabled=false、delivery_configured=false |
| F08 执行确认 | 机制通过，真实写入待验收 | 工具白名单、离线确认边界、真实模型拒绝绕过；未测试实际订单创建与付款 |
| F09 适老语音与交互 | 部分完成／待现场 | 界面和真实 ASR/TTS 网关已有证据；真人麦克风、老人可用性未现场验收 |
| F10 观测与失败处理 | 部分通过 | 有 trace、任务回执与离线错误边界；未来提醒和跨领域执行还需真结果验证 |
| F11 干净环境交付 | 待验收 | 启动脚本、锁文件与文档已有，尚无干净机器最终复现结果 |

## 审阅发现

1. 普通聊天测试要求简短两句，实际回复了列表和反问。聊天能力成立，简洁度还需要改善。
2. 任务查询回复夹带 running/completed，适老呈现应统一成清楚的中文状态。
3. 任务查询会把“当前这次查询”也列为进行中，说明现阶段是执行回执，不是独立生活目标管理。
4. 已忘事实不再回到回答或有效资料，不代表旧审计文件被物理擦除。

## 下一步顺序

1. 先补 F06：独立目标 ID、缺参追问、补充后继续、取消、重启后的可信状态。
2. 补 F07：一个真实提醒的创建／查询／修改／取消／触发／通知闭环，说明 Mac 睡眠与服务退出条件。
3. 补 F05：引入高德等第二生活领域，并使用同一份个人资料完成跨领域演示。
4. 真人语音、适老呈现、真实交易及干净环境交付逐项验收。
