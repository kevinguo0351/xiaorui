# PR #1 选择性整合与验证

整合日期：2026-11-05。来源：[Kevin 的 PR #1](https://github.com/perry112926-ai/xiaorui/pull/1)，源提交 `60f4425da1c35dd7142570a50db3bbac481d20f2`。按用户选定范围整合到现有 React 主线，不整批合并 PR。

## 已保留

- 陪伴角色与三套透明 PNG 素材；按真实录音、播报和任务状态切换，支持减少动态。
- 顶部助手头像／名字入口：修改昵称、选择头像、打开家人设置。昵称头像只在当前浏览器保存，不修改 Agent 固定身份。保留原有资料卡入口和页面布局。
- 录音停止后释放麦克风；识别等待期间可取消；提前结束和迟到结果隔离；通话增加“我说完了”和明确挂断反馈。
- 工具实际进度提示及后端耗时记录；补齐当前 main 新增的定位、地址草稿和多件餐品工具。
- 保留本地主线的整段渐进 MP3 播放和自适应停顿；增加请求、流地址就绪、播放开始／结束时间记录，不记录正文。
- 家人配置页支持现有豆包文本／语音、麦当劳、瑞幸和滴滴。密钥仅写本机 `.env`，读取接口不返回明文；空白保留、明确清除、环境变量优先和交易开关边界保留。
- 内置服务只读连接检查及命令行检查器；强化日志中 URL 编码凭据的遮蔽。
- 可选强制只读模式，页面明确标注；禁止交易及配置修改，兼容现有流式语音准备接口。
- 始终注册静态资源路由，加入角色素材路由，避免在构建间隙启动导致资源路由缺失。

## 本轮不合入

整页配色和侧栏重设计、长按说话、逐句语音预取、Flutter 客户端、Linux 桌面和启动工具。原有定位、配送地址、多件餐品、资料卡及交易确认逻辑保留。

## 使用入口

- 点击顶部助手头像／名字，进入“外观与名字”或“家人设置”。保存服务配置后再检查连接；文本和语音仍需实际对话验证。
- 只读运行：`XIAORUI_READ_ONLY=1 uv run uvicorn app.main:app --host 127.0.0.1 --port 8000`。这是当前进程的后端策略，重启并移除此环境变量后恢复正常模式；不会修改本机交易开关。
- 服务检查：`uv run python -m experiments.read_only_service_check`。只使用固定公开地点，不创建订单、叫车、取消或支付。

## 本机验证

- 后端：`python -m unittest discover -s tests -q`，228 项通过。
- 前端：`node --test frontend/tests/*.test.cjs`，36 项通过。
- TypeScript 与 Vite 生产构建通过。
- FastAPI TestClient 实际路由验证：首页、构建资源、三套角色图片可访问；只读模式可准备流式播报，禁止定位写入、动作确认及新增配送地址动作。
- 真实公开服务检查：麦当劳、瑞幸、滴滴的工具目录读取及固定公开地点查询均通过。详见 [检查结果](pr1-selected-public-services.json)。交易尝试数均为 0。

边界：未在本轮验证真人麦克风、扬声器回声、手机手势或完整真实语音对话；未重新进行真实交易验收。自动化交互测试及静态资源检查不等于本轮已完成浏览器视觉验收。以上结果不能据此扩大为下单、叫车或支付成功。
