# 温暖紧凑版：设计与家人设置验收

本轮保留原版 React 与既有 FastAPI Agent，按六项反馈重新设计界面。

## 已交付

1. 桌面左侧身份／设置区、举牌工作小人；手机折叠为顶部身份区。
2. 三张一致角色的透明 PNG：举牌、打车、点餐；CSS 循环与实际录音／处理状态驱动动态，支持减少动态，不冒充已完成订单。
3. 头像入口可改显示名字、选择三个头像样式，保存在当前浏览器；页面标题和日常显示同步更新。服务端 Agent 的固定身份提示不随显示昵称变更。
4. 家人设置可填写豆包文本、豆包语音、麦当劳、瑞幸、滴滴的现有配置。密钥只写本机后端 `.env`，读取只返回配置状态；空白保留原凭据，清除需明确选择并保存。环境管理项不可在此覆盖。
5. 输入框直接长按约 350ms 启动语音；松开发送，上滑取消。短按保留打字，识别等待期间不接受第二次长按；重复错误会退出长按状态。350ms／滑动距离均为设计初值。
6. 暖纸色、深绿与陶土色、紧凑卡片和输入区。主要辅助文字颜色 `#5f6b5b`，对纸色背景计算对比度约 5.1:1；主要操作维持至少 56px。

## 明确边界

- 这是透明 PNG＋CSS 动画，不是已生成的逐帧 GIF；可继续替换为 GIF／WebP 素材。
- 只支持已接入的五类 API/MCP 配置，自定义服务器、任意命令和其他 API 尚未接入。文本服务地址限定官方豆包端点。
- 配置存在不等于远端连通。麦当劳／瑞幸／滴滴可运行固定公开地标的只读检查；文本／语音当前只检查本地字段，真实对话另验。
- 本机仍缺少真实服务凭据。没有发起真实平台查询、下单、取消或付款，也未用假数据展示成功。
- 保存配置不会开启交易权限。停止播报、取消录音、挂断继续沿用原有明确边界。
- 真实手机的原生长按、文本选择、滚动、权限弹窗，以及真人语音与回声仍待实机验证。昵称／头像当前仅在该浏览器保存，不是跨设备资料。

复现：`uv run python -m unittest discover -s tests -q`、`node --test frontend/tests/*.test.cjs`、`npm --prefix frontend run build`。
