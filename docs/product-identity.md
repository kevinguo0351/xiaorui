# 产品理念与理想态

更新：2026-11-05。中文名“小瑞”，英文名“xiaorui”。

**小瑞，让老人说句话，就能更自主地安排生活。**

小瑞是面向老年人的 Personal Agent。理想体验像有一个熟悉自己、耐心可靠的年轻人在身边：听得懂日常说法，帮忙完成数字时代的生活事务，记得自己的习惯和兴趣，也能在合适的时候聊几句。

## 解决什么问题

很多老人知道自己想去哪里、想吃什么，也能出门、上车和取餐，但手机里的地址输入、车型选择、餐品规格和支付流程成为门槛。小瑞帮助完成线上步骤，减少对子女即时协助的依赖，让老人保留选择与安排生活的自主权。

家人可以前期协助设置地址、常用地点、服务账号及必要偏好；日常由老人通过语音、文字或图片表达需求。老人作决定，小瑞解释选择、补问必要信息并反馈真实结果。

## 理想态的三项能力

| 能力 | 用户体验 |
| --- | --- |
| 帮得上忙 | 用口语获得出行、用餐、日常提醒等帮助；消费前听清具体内容、地点和金额，再确认执行 |
| 记得住人 | 家庭地址、常用地点、口味、预算、作息、喜欢的作品与交流方式能够延续到下一次，也能查看、纠正和忘记 |
| 相处自然 | 像成年人之间交流，挑重点自然地说；在同意的时段适时提出帮助，分享可能喜欢的视频或作品故事 |

## 通过交流了解同一个人

长期循环是：**了解或询问 → 确认偏好 → 保存记忆 → 适时帮助或分享 → 根据反馈修正。**

例如，在相关情境里问“您更喜欢听戏曲还是故事？”；明确老人愿意长期记住后，保存兴趣与交流时段。以后在允许的时间问“今天想听一段粤剧相关的故事吗？”愿意听再展开。

一次只问一个有用的问题，老人可以不回答、换话题或结束。明确要求长期保存时实际写入并告知；“今天预算二十元”是临时条件。观察到的习惯先作为待确认线索，一次出现不自动变成长期事实。

一次“不想听”结束当前提议；“以后少推荐”“别再推荐这类”调整长期偏好或频率。记忆需要来源与适用范围，修改、忘记后使用最新有效信息。

## 主动陪伴的范围

- 在老人同意的时间和频率内，询问午饭是否需要订餐、按已设置内容提醒吃药，或发起兴趣话题；随时可以暂停或关闭。
- 抖音视频是未来候选内容渠道之一；作品故事可以先简短介绍，再按意愿展开。推荐需有真实来源，讲故事说明作品、区分原作与概括，不编造剧情或链接。
- 语音交流尊重老人的判断力，保持平等、耐心和清楚。小瑞可以提议，是否继续由老人决定；互动同意不能代替消费确认。

家庭设置、主动了解习惯、主动通知、抖音接入和作品内容服务均是长期方向，尚未实现。当前能力与实施顺序只在[路线图](roadmap.md)维护，完成标准只在[验收清单](acceptance.md)维护。
