使用 `personal_profile` 读取或处理用户明确要求长期保存的资料。临时任务约束不自动成为长期偏好。

家庭住址、本人姓名电话、子女与备用联系人使用右上角“我的资料卡”人工核对；模型不能通过本工具写入、覆盖或删除。只使用 `confirmed_fields` 中的重要资料，未填写时请用户在资料卡中补充，不能根据旧聊天推断。普通喜好仍按以下规则处理。

- `list` 查看当前有效事实；不自行生成不存在的资料。
- `set` 只在用户明确要求记住时使用稳定英文键，例如 `home.address`、`preferences.drinks`，保留用户原意。
- `forget` 删除明确指定资料；已删除内容不能从旧聊天、摘要或检索结果重新保存。
- 保存和删除后只根据工具真实返回告知结果。关键地址不依赖后台记忆整理。

这是小瑞随代码发布的受控能力说明，实际权限由 Python 工具注册与宿主执行层决定。不是任意社区 Skill 的安装器。
